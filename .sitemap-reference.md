# Career Blog — Site Structure Reference

Generated: 2026-05-07
For subagent use: read this file instead of exploring the codebase.

## Site Stack
- **Generator:** Hugo v0.160.0
- **Theme:** blowfish (overridden heavily)
- **Config dir:** `config/_default/`
- **Content dir:** `content/`
- **Theme dir:** `themes/blowfish/` (usually don't modify)
- **Custom layout overrides:** `layouts/` (preferred edit location)
- **Custom CSS:** `assets/css/custom.css` (primary CSS override)
- **Critical CSS:** `assets/css/critical.css` (secondary, don't touch unless needed)
- **Base font:** EB Garamond (Google Fonts import in custom.css)

## Config Files
- `config/_default/hugo.toml` — Hugo site config (baseURL, theme, taxonomies, etc.)
- `config/_default/params.toml` — Theme options (colorScheme, homepage layout, article settings, etc.)
- `config/_default/menus.en.toml` — Main + footer menu structure
- `config/_default/languages.en.toml` — Language config
- `config/_default/markup.toml` — Goldmark/markdown settings

### Custom CSS (`assets/css/custom.css`)
- Imports EB Garamond font
- Sets `--font-sans` and `--font-serif` to EB Garamond
- Overrides body, p, headings font-family
- Scroll reveal animations (IntersectionObserver)
- Gallery thumbnail styling
- List page full-width
- Sticky table headers

## Key Styling Targets
- **Global `<p>`:** Controlled by `critical.css` — `p { font-size: 16px; line-height: 28px; color: #333; }` and `custom.css` overrides font-family to EB Garamond
- **Landing page `<p>`:** Controlled by inline CSS in `custom.html` — `#anchor p { font-size: 14px; ... }`
- **Homepage config:** `config/_default/params.toml` — `[homepage] layout = "custom"`
- **Theme compiled CSS:** `themes/blowfish/assets/css/compiled/main.css` (avoid editing)
