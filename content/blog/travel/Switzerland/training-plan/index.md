#### Target Power Profile

| Section | Grade | Pace | Power |
| :--- | :--- | :--- | :--- |
| Moderate start | 4.5% | 12 km/h | 118 W (Z2) |
| Mid-section | 6.8% | 11 km/h | 157 W (Z3 high) |
| Long grind | 7.8% | 10.5 km/h | 170 W (Z4) ← main effort |
| Upper switchbacks | 7.7% | 10.5 km/h | 168 W (Z4) |

→ Total Susten climbing: ~100 min continuous
→ Core effort (Z4): ~60 min

Your 250W bursts on Singapore climbs = Z5+ surges. Susten is the opposite — not higher power, but **holding Z3-Z4 for 4× longer than any climb here.**

#### Power Zones Reference

| Zone | %FTP | Feel | Trainer cue |
| :--- | :--- | :--- | :--- |
| **Z1** | <55% | Spinning, no load | Just turn legs over |
| **Z2** | 56–75% | Chatty endurance | Ride by feel, wide range |
| **Z3** | 76–90% | "Comfortably hard" | Sweet spot for climbing efforts |
| **Z4** | 91–105% | Threshold, hold 20–60 min | Hard but steady |
| **Z5** | 106–120% | VO₂max, 3–8 min | Breathing hard |
| **Z6** | 120%+ | Sprints / neuromuscular | Short, explosive |

> **Trainer rule:** Zones are ranges. Staying anywhere in the zone is a win. If you're bouncing between Z3 floor and Z4 ceiling on a climb, that's fine.

### Phase 1: Accelerated Power Build

| Week     | Date        | Focus                                |
| :------- | :---------- | :----------------------------------- |
| 1 -3     | May 11 - 31 | Torque capacity & muscular endurance |

Build the raw strength to turn a low cadence under load. Singapore is flat — so every hard session is done at <70 RPM to simulate the torque of alpine grades.

| Session                     | Frequency      | What                                                                                                                                                             |
| :-------------------------- | :------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Climbing Intervals** (AM) | Tue + Thu      | Low cadence blocks on trainer.<br>Week 1: 4×10 min → Week 2: 4×12 min → Week 3: 5×12 min.<br>All at **Z3**, <70 RPM, 2 min Z1 recovery. Main set minimum 45 min. |
| **Hill Repeats** (AM)       | Sat            | Find the steepest continuous bit available (BCM, Mandai)<br>5–8 × 2–3 min max effort, low cadence<br>Or trainer: 10 × 2 min @ **Z4**, 60 RPM                     |
| **Endurance** (AM/PM)       | Wed, maybe Sun | 60–90 min **Z2**, normal cadence.<br>Flush legs, keep CTL from dropping.                                                                                         |
| **Z2 Spin** (AM)            | Wed            | Recovery between hard days.<br>45–60 min **Z1–Z2**                                                                                                               |
|                             |                |                                                                                                                                                                  |

**Success signal:** Able to sustain **20+ min at <70 RPM at Z3** without form breaking down.

**If HRV drops** → swap a hard session for active recovery.

#### Overseas Trip Block: Active Maintenance

**May 29 – Jun 7 — Don't lose fitness, don't gain fatigue**

You're travelling. Focus on maintenance, not gains.

| Option | What |
| :--- | :--- |
| 🏃 Run | 3–4 × 30–45 min easy runs. Maintain aerobic engine |
| 🚲 Ride | If you find a spin bike: 2 × 20 min @ **Z3**, normal cadence |
| 💪 Bodyweight | Core + glute activation circuits. 15 min, 3×/week |
| **No stress** | If you only run 3 times and do nothing else — that's fine |

**Key rule:** Come back June 8 fresh and ready for Phase 2.

### Phase 2: Specificity

**Weeks 5–8 (Jun 8 – Jul 5) — Focus: Sustained climbing power + back-to-back durability**

This is the meat of the plan. Intervals get longer and more route-specific. Susten is a 60–90 min Z3-Z4 effort — so we train for that.

| Session | Frequency | What |
| :--- | :--- | :--- |
| **Sustained Threshold** (AM) | Tue | Build from 2×15 min @ **Z3** → 2×20 min @ **Z3-Z4 border** → 1×45 min @ **Z3** → 1×30 min @ **Z4** by Week 8 |
| **Torque Threshold** (AM) | Thu | 3–4×10–15 min @ **Z3**, <70 RPM. Grimsel simulation |
| **Back-to-Back Weekend** | Sat + Sun | See below |
| **Easy Z2** (AM) | Wed | 60 min **Z1–Z2** flush |

### Notes on Riding Craft

#### Descending (Day 3)

Day 3 drops **30 km / 1,600 m** from Sustenpass to Meiringen.

- You can't train descending in Singapore. Practice cornering confidence on empty roads.
- Body position: outside pedal down, outside hand on drops, inside knee into the turn.
- Brake before the corner, not in it.
- **Smooth is fast.**

#### Route-Specific Milestones

| Milestone | What it means | Phase |
| :--- | :--- | :--- |
| 20 min @ <70 RPM, Z3 | Torque endurance baseline | Phase 1, Week 3 |
| 2×20 min @ Z3-Z4 border | First Susten core simulation | Phase 2, Week 6 |
| Back-to-back hard + steady feels OK | Fatigue resilience confirmed | Phase 2, Week 7 |
| 1×45 min @ Z3 | Susten long effort simulation | Phase 2, Week 8 |
| 1×30 min @ Z4 (fatigued) | Day 3 Susten after prior days | Phase 2, Week 8 |
| HRV steady during taper | Fresh for August | Phase 3 |

#### Rules of the Road

1. **Recovery first** — bad sleep? Skip the hard session.
2. **Track on Intervals.icu** — I'll monitor ATL/CTL/TSB.
3. **London:** Maintenance only. Don't chase lost training.
4. **De-load is not optional.** Week 7 matters as much as Week 8.
5. **If in doubt** — rest day, not a hard day.
6. **Zones > % targets.** Staying in the zone is a win.
